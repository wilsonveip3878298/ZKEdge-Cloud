DEVICE IDENTITY
========================

La identidad REAL del biométrico NO debe basarse en IP local.

Debe basarse en:

- serial único
- MAC address
- modelo
- firmware
- edge_id
- branch_id

Ejemplo:

{
  "serial": "ZK6A22003991",
  "mac": "AA:BB:CC:DD",
  "model": "MB360",
  "firmware": "6.66"
}

IMPORTANTE:
- La IP local puede cambiar
- El serial es la identidad permanente
- El cloud debe mapear SERIAL → Sucursal → Empresa
